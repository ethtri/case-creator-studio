# Catalog Image Provenance

**Last verified:** 2026-07-20
**Rights basis:** Written permission from KeMore is held by the Snapcase owner
outside the repository.

The catalog uses local, optimized WebP derivatives so the customer experience
does not depend on vendor-CDN availability. The source files were retrieved
from KeMore/Kexiaozhan's device catalog and official printable-case product
page. The repository's older generated mockups were not used.

## Usage

- iPhone 14-16 and Galaxy S24 cards use the corresponding KeMore device
  reference image.
- KeMore's customer catalog did not expose model-specific iPhone 17 images
  during verification. Those four cards use the official KeMore print-finish
  sample and label it `Finish sample`; they do not substitute another phone
  model.
- Catalog copy and image alt text state that the phone is not included.
