# Catalog Image Provenance

**Last verified:** 2026-07-20

**Rights basis:**

- Written permission from KeMore is held by the Snapcase owner outside the
  repository.
- The four iPhone 17-family reference photos are released under the Creative
  Commons CC0 1.0 public-domain dedication.

The catalog packages source-provided image sizes locally so the customer
experience does not depend on third-party availability. KeMore images are
optimized WebP derivatives. The iPhone 17-family files are unmodified
Wikimedia Commons thumbnails, with presentation cropping handled only by CSS.
The repository's older generated mockups were not used.

## Usage

- iPhone 14-16 and Galaxy S24 cards use the corresponding KeMore device
  reference image.
- iPhone 17 Pro Max, iPhone 17 Pro, iPhone Air, and iPhone 17 use
  corresponding CC0 device-reference photographs while model-matched KeMore
  images are unavailable.
- The customer-facing `iPhone Air` name follows Apple's official product name;
  the internal `iphone-17-air` identifier remains unchanged for fulfillment
  compatibility.
- Catalog copy and image alt text state that the phone is not included.

## Refresh rule

Replace an asset only with a model-matched KeMore source or an appropriately
licensed model-matched reference. Update the source and license record in the
same change. Do not silently map a different device image as a fallback.
