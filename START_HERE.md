## 🚀 Quick Start (3 Steps)

### Step 1: Set Up Pre-commit Hooks (One-time)

```bash
npm install --save-dev husky
npx husky init
```

This will automatically check your code before every commit!

### Step 2: Create Environment File

If you don't have a `.env` file yet, create one with your API keys:
- Supabase URL and keys
- Printful API key
- Stripe secret key

### Step 3: Start Using the Workflows

Before every commit, run:
```bash
npm run check
```

This ensures everything is working correctly!
